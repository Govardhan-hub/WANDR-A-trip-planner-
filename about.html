About WANDR

A modern, AI-powered travel planning platform built to make exploring the world effortless and intelligent.

Project Overview

Reimagining Travel Planning with Artificial Intelligence

WANDR is a full-featured frontend web application that demonstrates how modern web technologies can be combined with AI-inspired logic to create intuitive, beautiful, and functional travel tools.

The platform allows users to explore curated destinations, filter by travel categories, select famous places, enter preferences, and receive a fully personalized day-by-day itinerary — complete with budget estimates, hotel recommendations, and activity suggestions.

  • Smart AI itinerary generation based on user preferences
  • Dynamic category filtering with animated country cards
  • Interactive place selection system
  • Responsive design for mobile, tablet and desktop
  • Dark mode with persistent theme storage
  • Scroll reveal animations and smooth transitions
  • Budget breakdown with visual analytics
    • HTML5 CSS3 JavaScript ES6+
